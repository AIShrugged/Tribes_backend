# Чейнджлог: Insight API, линковка идентификаторов, новые тулзы агента

**Дата:** 18 февраля 2026

---

## Что сделано

### Insight API
Полный набор эндпоинтов для доступа к накопленным знаниям о людях:
- `GET /insight/profile` — долгосрочный профиль (все 6 категорий + отношения)
- `GET /insight/short-term` — активный краткосрочный контекст
- `GET /insight/items` — сырые факты с фильтрацией по категории
- `GET /insight/sources` — источники, из которых собраны знания
- `GET /insight/history` — история изменений профиля по версиям
- `GET /insight/relationship` — динамика отношений между двумя людьми
- `DELETE /insight/forget` — GDPR: полное удаление всех данных профиля

### Линковка идентификаторов (`UserIdentityController`)
Пользователь может привязать к аккаунту несколько каналов (Telegram, Google Calendar, Zoom):
- `GET /users/me/identities` — список привязанных каналов
- `POST /users/me/identities` — привязать канал
- `DELETE /users/me/identities/{channel}` — отвязать канал

При регистрации анонимные профили (Google Calendar) автоматически привязываются к новому аккаунту по email (`ProfileLinkingService`).

### Новые тулзы агента
Агент теперь умеет отвечать на конкретные вопросы о встречах и людях:
- `GetMeetingSummaryTool` — структурированное саммари встречи с решениями
- `GetMeetingTasksTool` — задачи из встречи с фильтрацией по исполнителю и статусу
- `GetExtractedFactsTool` — сырые факты о человеке из конкретной встречи
- `GetFollowupTool` — оценки по методологии (DISC и др.) после встречи
- `GetInsightProfileHistoryTool` — как менялся профиль человека с течением времени

Старый `GetMeetingInsightsTool` удалён — заменён более точными специализированными тулзами.

### Авторизация
`ProfilePolicy` — контроль доступа к данным профиля:
- просматривать может владелец или хост встречи, в которой участвовал человек
- удалить данные (forget) может только владелец

---

## Бизнес-ценность

**Insight API** открывает накопленные знания для фронтенда: HR-менеджер видит профиль сотрудника, историю его развития и отношения с коллегами — без ручного ввода, на основе реальных встреч.

**Линковка каналов** — человек строит один профиль из всех источников. Данные из Zoom, Telegram и Google Calendar объединяются. Агент знает о человеке всё, вне зависимости от того, через какой канал с ним общаются.

**GDPR forget** — соответствие законодательству: пользователь может запросить полное удаление своих данных одним запросом.

**Новые тулзы агента** дают точные ответы на конкретные вопросы: «что решили на встрече в пятницу», «какие задачи висят на Иване», «как изменилась коммуникация Алексея за последние 3 месяца».
