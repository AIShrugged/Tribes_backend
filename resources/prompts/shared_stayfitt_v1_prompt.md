## Входные данные
Файл с транскриптом одной встречи между менеджером по продажам и клиентом.  
Формат транскрипта — список реплик с указанием имени говорящего и временной отметки.

### Пример входа:
```
0:02 - Ekaterina Gudozhnikova  
  Здравствуйте, коллеги! Хотела бы спросить, можем ли мы поставить встречную запись, потому что будем обсуждать детали.

0:40 - Влада  
  Екатерина, да? Здравствуйте. Смотрели предложение, у нас есть корректировки и вопросы для уточнения.
```

---

## Задача ИИ
1. Определить роли участников транскрипта кто является клиентом, а кто менеджером по продажам.
2. На основе методики Stayfitt извлечь структуру оценки.
3. Проанализировать разговор по этапам продаж.
4. Рассчитать баллы по каждой метрике согласно шкале (от 0 до 4).
5. Сформировать общее заключение по работе менеджера:
    - Сильные стороны
    - Зоны для развития
    - План действий
6. Вернуть всё в виде JSON по указанной схеме.

---

## Шкала оценивания (для всех метрик)
- **0** — отсутствует / выполнено плохо.
- **1** — требуется серьёзное улучшение.
- **2** — удовлетворительно, но можно лучше.
- **3** — хорошо, заметный вклад в разговор.
- **4** — отлично, мастерское выполнение.

---

## Метрики и диапазоны оценок

### A. Подготовка к звонку
- client_research_and_goal_setting (0–4)

### B. Структура встречи
- small_talk (0–4)
- agenda_setting (0–4)
- loyalty_building (0–4)
- spin_questions:
    - situational (0–4)
    - problem (0–4)
    - implication (0–4)
    - need_payoff (0–4)

### C. Презентация продукта
- product_presentation_alignment (0–4)

### D. Обсуждение предложения и следующих шагов
- proposal_discussion (0–4)
- commitment_to_next_steps (0–4)

### E. Работа с возражениями
- objection_handling:
    - algorithm_adherence (0–4)
    - response_effectiveness (0–4)
    - proactive_prevention (0–4)

### F. Коммуникация
- language_and_communication:
    - clarity (0–4)
    - empathy (0–4)

## Выходной формат: JSON

Ожидаемый результат должен соответствовать следующей JSON-схеме:

```json
{
  "total_score": <integer>,
  "metrics": {
    "client_research_and_goal_setting": <0-4>,
    "small_talk": <0-4>,
    "agenda_setting": <0-4>,
    "loyalty_building": <0-4>,
    "spin_questions": {
      "situational": <0-4>,
      "problem": <0-4>,
      "implication": <0-4>,
      "need_payoff": <0-4>
    },
    "product_presentation_alignment": <0-4>,
    "proposal_discussion": <0-4>,
    "commitment_to_next_steps": <0-4>,
    "objection_handling": {
      "algorithm_adherence": <0-4>,
      "response_effectiveness": <0-4>,
      "proactive_prevention": <0-4>
    },
    "language_and_communication": {
      "clarity": <0-4>,
      "empathy": <0-4>
    }
  },
  "conclusion": {
    "strengths": [
      "Сильные стороны менеджера, подкреплённые примерами из транскрипта"
    ],
    "areas_for_development": [
      "Зоны развития, подкреплённые примерами из транскрипта"
    ],
    "action_plan": [
      "Конкретные шаги по развитию (тренинги, отработка навыков, коучинг)"
    ]
  }
}
```

---

## Дополнительные требования
- В блоках **strengths**, **areas_for_development** и **action_plan** текст должен быть на русском языке и адаптирован для руководителя.
- Обязательно использовать **цитаты из транскрипта** для подтверждения выставленных оценок.
- Итоговый **total_score** = сумма всех метрик (максимум 72).

## Цель
Сформировать полноценную автоматизированную систему оценки эффективности работы менеджеров по продажам по методике Stayfitt.
